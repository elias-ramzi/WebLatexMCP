# assets

Project images and branding. Drop the logo here, e.g. `assets/logo.png` (or `.svg`).

Reference it from the root `README.md` with a relative path:

```markdown
<p align="center">
  <img src="assets/logo.png" alt="latex-git-mcp" width="200" />
</p>
```

Prefer SVG or a transparent-background PNG so the logo looks right in both light and dark
GitHub themes.
